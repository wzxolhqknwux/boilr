## Overview

BoilR synchronizes games from Epic Games, GOG, Xbox Game Pass, EA App, Amazon, Ubisoft Connect, and other launchers into your Steam library as non-Steam entries, automatically downloading matching capsule, hero, and icon artwork from SteamGridDB. It runs in the background as a scheduled sync daemon, keeping your Steam library current as new games are installed across platforms.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **BoilR** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Multi-Launcher Sync** | Imports Epic, GOG, Xbox, EA App, Amazon, and Ubisoft games to Steam |
| **Automatic Artwork** | Downloads matching capsule and hero art from SteamGridDB automatically |
| **Steam Integration** | Adds entries with correct launch commands and Big Picture compatibility |
| **Background Daemon** | Scheduled sync keeps Steam library current as games are installed |
